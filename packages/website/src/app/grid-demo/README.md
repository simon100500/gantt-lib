# Эксперимент: SimpleGrid внутри GanttChart

Запуск: из `packages/website` выполнить `npm run dev`, открыть http://localhost:3005/grid-demo.

TaskList заменён настоящим SimpleGrid ревизии `500a94577daa7f9bd4b4e0ea96d90804d65b401f`. Таблица и диаграмма находятся внутри одного `.gantt-scrollContainer`; внутренний viewport SimpleGrid отключён. Высоты строк и список видимых задач приходят из GanttChart. Фильтр, сортировка и изменение высоты строк SimpleGrid отключены, чтобы не расходиться с диаграммой. Виртуализация строк таблицы пока отсутствует.

Проверка: выделить название первой дочерней задачи и вставить из Excel блок 2×3 (название, начало, окончание) с датами в пределах строк. Меняются значения и полосы. Кнопка слева от родителя сворачивает его в обеих панелях. Колесо над любой панелью прокручивает общий контейнер.

В режиме с `onScheduleIntent` допускается изменение одной даты; прямоугольник с несколькими изменениями дат или с именем и датой отклоняется, поскольку существующий контракт принимает один intent. Без `onScheduleIntent` пакет детей проходит через последовательные расчёты scheduler по обновляемому снимку и отдаётся одним `onTasksChange`; пакет, меняющий даты родительских задач, отклоняется. Вставка за границы существующих строк также отклоняется.

Пока не перенесены пользовательские колонки, изменение длительности и прогресса, действия/меню, управление связями, перетаскивание задач в списке, привязка размеров и порядка колонок к публичным callbacks, режимы печати и виртуализация. Существующие тесты TaskList показывают регрессии: эксперимент не готов к выпуску.
