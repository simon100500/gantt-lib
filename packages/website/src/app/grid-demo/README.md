# SimpleGrid в GanttChart

Из корня репозитория запустите `npm run dev -w website` и откройте `http://localhost:3005/grid-demo`.

Таблица использует исходный компонент SimpleGrid. Gantt передаёт ему тот же порядок, высоты и окно видимых строк, что и таймлайну. Обе панели прокручиваются вместе. На узком экране таблица прокручивается по горизонтали вместе с датами.

- Потяните за номер строки. Верх и низ целевой строки задают позицию вставки. Середина обычной строки позволяет сделать её родителем. Перенос группы включает свёрнутых потомков.
- Раскройте «Каркас и перекрытия». В обеих панелях появятся компактные строки этажей. Прокрутите по обеим осям и проверьте, что границы строк и заголовков совпадают.
- Откройте календарь, измените длительность, прогресс или ответственного. Изменения дат и длительности сразу после подтверждения отражаются на таймлайне. В поле длительности доступно предварительное окончание.
- Вставьте из Excel блок с названиями и датами в пределах существующих строк. Меню в строках позволяет вставить работу, дублировать, менять уровень и удалять задачи.

Сортировка, фильтрация и высота строк задаются Gantt. В управляемом режиме `onScheduleIntent` обрабатывает одну операцию с датами за раз. Вставку за пределы существующих задач и неподдерживаемые пакетные изменения дат таблица отклоняет с сообщением.
